## Numerical Results

$h_1 = 0.767$
$h_2 = 0.614$

## Overview

After ~4000 steps of the simulation we see most parameters neatly converge to a solution according to the trail plot, especially $h_1 = 0.767$. However, $h_2$ tends to be more problematic, starting to generally converge in the first ~750 steps, then searching the a larger space, and finally beginning to settle in the last ~1000 steps, giving a fit report value of $h_2 = 0.614$. This is confirmed by the corner plot, where the parameters mostly settle as circles (albeit irregular) apart from $h_2$, which suggests another problem.

Also note that this simulation was run without priors, but the script has the capability to include priors which was previously attempted. The conclusion was that the simulation runs better allowing the walkers to converge naturally, rather than forcing them into a certain area when they begin to find a solution elsewhere.
